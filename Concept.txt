CONCEPT – Road accidents in Belgium 2017–2024
=============================================
Design of the project (step 1 of the assignment, "Design first"). It describes what the dashboard answers, how the
question is broken down (the four pillars of computational thinking), and draws every tab: sub-questions,
categories, columns, filters and pipeline steps. A reader should be able to explain the dashboard without asking.

Data: Statbel "Geolocatie van de verkeersongevallen 2017–2024" (289,532 accidents with at least one death or injury)
      + Statbel population & area per municipality + Statbel municipality borders (statistical sectors 2024)
      + Google COVID-19 Community Mobility Reports (BE, 2020–2022) + Oxford COVID-19 Government Response Tracker.
Code: pipeline.py (all steps, pure functions) -> Data/Processed Data -> app.py (Streamlit, only shows).


#####################################################################################################################
PART A – THE CENTRAL QUESTIONS
#####################################################################################################################

Q1  "Is it true that as the density of the population increases, the severity of the accidents decreases? Why?"
Q2  "Did the COVID-19 lockdowns make road accidents fewer but more severe? Why?"

Key definitions (same everywhere, see CLAUDE.md):
  * Severe accident  = CD_CLASS_ACCIDENTS 1 (with deaths), 2 (fatally injured) or 3 (seriously injured).
                       Class 4 (only light injuries) = not severe.
  * Severity Ratio   = severe accidents / all recorded injury accidents x 100. Each accident counts once.
  * Population density = population on 1 January / area (km2), of the municipality, in the year of the accident.
  * "Normal" (Q2)    = average of the same calendar month in 2017, 2018 and 2019.

PART B – THE FOUR PILLARS

=====================================================================================================================
B1. DECOMPOSITION – break the big question into small questions you can answer one by one
=====================================================================================================================

Q1 – density vs severity
  1.1  Is the data good enough?  What is missing, unknown or wrong in the accident file?        -> tab 1.1
  1.2  Which accidents can we place on a map, and what do we do with the ones we cannot?        -> steps 5–8, tab 1.2
  1.3  How dense is the municipality where each accident happened, in that year?                 -> step 4
  1.4  What is the Severity Ratio per region / province / municipality / Belgium?                -> tab 2, map + table
  1.5  Do denser units have a lower Severity Ratio? How strong is the relation?                  -> tab 2, scatter + rho
  1.6  WHY? What is different about accidents in dense areas?
         a. Where do they happen?  (inside / outside built-up area, motorway)                      -> tab 2, charts 2–3
         b. What kind of crash?    (single vehicle / obstacle, pedestrian, frontal, rear-side)     -> tab 2, chart 4
         c. Under which conditions? (night without street lighting)                               -> tab 2, chart 2
         d. Does density still matter INSIDE built-up areas (same speed regime)?                  -> tab 2, chart 3
  1.7  What can the data NOT tell us? (only injury accidents, no traffic volume, areas not people) -> assumptions box

Q2 – COVID
  2.1  When were the lockdowns, and how strict were they?                                       -> OxCGRT, phases
  2.2  How much did people move during each phase?                                               -> Google mobility
  2.3  How many accidents and severe accidents happened per month, compared with normal?         -> tab 3, time series
  2.4  Was the Severity Ratio in Lockdown 1 / Lockdown 2 different from normal, and significant?  -> tab 3, metrics
  2.5  Is the change the same in Flanders, Wallonia and Brussels?                               -> tab 3, area buttons
  2.6  WHY? Did OTHER accidents happen (mix), or did the SAME accidents end worse (within)?       -> tab 3, charts 1–3
  2.7  Does less mobility go together with fewer accidents / a higher ratio?                     -> tab 3, scatter

=====================================================================================================================
B2. PATTERN RECOGNITION – what repeats, what looks alike, what we expect to see
=====================================================================================================================

Patterns in the data (found while exploring, used in the design)
  * Every accident has a municipality code (CD_NIS) that maps to exactly one name and one region
    -> the municipality is the reliable "place" key; coordinates are not (12.7% unusable).
  * Missing coordinates follow the year: 15–19% before 2022, 3–6% from 2022
    -> missing values are not random over time; they must be shown per year.
  * The same structure repeats in every coded column: a code column (CD_...) + a Dutch label (TX_..._NL)
    + a code for "unknown" (9, 99, 0, -1, -3) -> one generic quality check for all coded columns.
  * The same calculation repeats at every level (municipality -> province -> region -> BE):
    count accidents, count severe, divide; sum population, sum area, divide
    -> one function (aggregate_by_level) for all four border views.
  * Rural areas: more accidents outside built-up areas, more single-vehicle crashes, more dark roads.
    Cities: many low-speed rear/side collisions. -> expected to explain Q1.
  * Accidents have a strong seasonal pattern (peaks in June and October)
    -> Q2 must compare a month with the same month in other years, not with the month before.
  * Lockdown months: mobility down 30–60%, accidents down; the 1st lockdown looks different from the 2nd
    -> Q2 treats each lockdown separately.

Patterns in the questions
  * Q1 and Q2 have the same shape: "does X go together with a higher/lower share of severe accidents, and why?"
    -> same Severity Ratio, same "why" approach: look at the MIX of accidents and at severity WITHIN each type.

=====================================================================================================================
B3. ABSTRACTION – what we keep, what we leave out, and the categories we choose
=====================================================================================================================

Kept / simplified
  * An accident = one row = one count (number of victims ignored, as the Severity Ratio definition says).
  * Severity: 4 classes -> 2 groups: severe (1-2-3) / not severe (4).
  * Place: municipality code (581 post-2019 municipalities) instead of the exact point for all numbers;
    the exact point only for the GPS heat layer.
  * Time: year (Q1) and month (Q2). The day is not in the data, the hour only for the rush-hour share.
  * Density: one number per municipality per year (1 January).
  * COVID: a phase per month instead of exact dates.

Left out on purpose
  * French columns (identical to Dutch).
  * Weather, road condition, obstacle details, crossway: not needed for the two questions (kept in the data, shown
    in the Raw Data Explorer quality checks).
  * Traffic volume (vehicle-km): not available -> we do not compute "risk per km driven" (stated in the app).
  * Accidents with only material damage: not in the data -> stated in both question tabs.

Categories (classification rules; full list in pipeline.CATEGORY_RULES, shown in the app)

=====================================================================================================================
B4. ALGORITHM – the steps, in order (pipeline.py; each step reports rows in / out / dropped / changed / why)
=====================================================================================================================

  PREPARE GEOGRAPHY                                                      rows in -> out (grouped, nothing lost)
    G1  Statbel statistical sectors 2024 (Lambert 72) dissolved into municipalities;
        centre = centroid (representative point if outside: 5 cases)    19,795 -> 581
    G2  Municipalities dissolved into 3 regions, 11 provinces (incl. Brussels), BE; centre + simplified
        borders for every border view                                     581 -> 596 units

  PREPARE POPULATION DENSITY
    P1  2019–2024: Statbel density per municipality as is. 2017–2018: population per municipality (old codes)
        -> map to 2019 codes (7 mergers + Hainaut renumbering) -> sum -> divide by the 2019 area.
        Check: Belgium 2017 = 11,322,088 (Statbel).                       5,120 sheet rows -> 4,648 (581 x 8)

  ACCIDENT STEPS                                                         rows in -> out     changed
    1  Load raw accidents (OPENDATA_MAP_2017-2024.xlsx)                  289,532 -> 289,532   –
    2  Drop the 14 French columns                                         289,532 -> 289,532   –
    3  Empty province (Brussels only) -> "Brussels Hoofdstedelijk Gewest" 289,532 -> 289,532   30,022
    4  Join population density on CD_NIS + year                          289,532 -> 289,532   289,532
    5  Check coordinates: missing / outside Belgium / > 1 km outside own municipality
                                                                          289,532 -> 289,532   36,628 flagged
    6  Replace flagged coordinates by the municipality centre             289,532 -> 289,532   36,628
    7  Convert Lambert 72 -> latitude / longitude                        289,532 -> 289,532   all
    8  View for the heat layer: only accidents at their own GPS position  289,532 -> 252,904   (not saved;
       a switch on the map can add the 36,628 at their municipality centre)

  COVID STEPS
    C1  Google mobility: keep Belgium + 3 regions, drop provinces         13,636 -> 3,896 rows; monthly mean
    C2  OxCGRT: keep Belgium (national)                                   202,760 -> 1,096 days; monthly mean
    C3  Per month x area: accidents, severe, Severity Ratio, "normal" (same month 2017–2019), phase,
        mobility, stringency -> covid_monthly_2017-2024.csv                289,532 -> 384 rows (4 areas x 96)

  ANALYSIS (in the app, with pipeline functions)
    Q1  for the selected years and border view:
          per unit: accidents, severe, SR = severe / accidents x 100, density = sum(pop) / sum(area)
          dot at the unit centre: colour = SR, size = density
          Spearman rho (density, SR) over municipalities; trend line weighted by sqrt(accidents)
          per density class: SR, % outside built-up area, % single vehicle, % unlit night; SR inside vs outside
    Q2  for the selected area and lockdown:
          accidents and severe vs normal; SR vs normal; chi-square test
          mix profile (shares) and SR per road-user group, lockdown vs normal
          decomposition: expected SR = normal SR per cell (built-up x road type x collision type x cyclist),
          weighted by the lockdown mix -> mix effect = expected - normal, within effect = observed - expected

PART E – ANSWERS (Belgium, all years) AND LIMITS
#####################################################################################################################
  Q1  Yes. SR 13.6% in municipalities < 250 inh/km2 vs 4.9% > 5,000 inh/km2; Spearman rho = -0.50 (581
      municipalities, p < 0.001). Why: fewer accidents outside built-up areas (61% -> 2%), fewer single-vehicle
      crashes (37% -> 12%), and even inside built-up areas the ratio falls (10.5% -> 4.9%).
  Q2  Yes for Lockdown 1: 42% fewer accidents, SR 12.3% vs 10.2% normal (p = 1.6e-06); mostly a within effect
      (+1.68 pp) rather than a mix effect (+0.49 pp) -> fits higher speeds on empty roads. No for Lockdown 2:
      25% fewer accidents, SR 9.6% vs 9.7% (p = 0.85).
  Limits: only injury accidents; no traffic volume (no risk per km); relations between areas, not individuals;
      12.7% of coordinates replaced (does not affect the ratios, grouped by municipality code); months only for COVID.

  More detail: decision_log.md (every choice: what, why, alternatives, impact), CLAUDE.md (agreements),
  tests/TEST_GAPS.md (what is tested and what not).
