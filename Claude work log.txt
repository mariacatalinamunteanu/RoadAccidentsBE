2026-11-15  |  Task: 3rd app tab – "Did the COVID-19 lockdowns make road accidents fewer but more severe? Why?"
------------------------------------------------------------------

1. Raw data
   - Data/Raw Data/COVID Mobility/: 2020/2021/2022_BE_Region_Mobility_Report.csv
       Google COVID-19 Community Mobility Reports (https://www.gstatic.com/covid19/mobility/Region_Mobility_Report_CSVs.zip).
       Only the 3 Belgian files kept; the worldwide zip (98 MB) was deleted after extraction.
       Daily % change vs Jan–Feb 2020 baseline, for Belgium, 3 regions, 11 provinces; 15/02/2020 – 15/10/2022.
       No "driving" category -> workplaces / transit / residential used as proxies.
   - Data/Raw Data/COVID Measures/: OxCGRT_compact_national_v1.csv (Oxford COVID-19 Government Response Tracker,
       https://github.com/OxCGRT/covid-policy-dataset), all countries, daily 2020–2022; Belgium used.

2. Processed data – Scripts/prepare_covid.py
   - covid_phases.csv: Pre-COVID 2020-01..02 | Lockdown 1 2020-03..05 | Summer 2020 2020-06..10 |
     Lockdown 2 2020-11..2021-04 | Reopening 2021-05..2022-02 | Post-COVID 2022-03..2024-12
     (based on OxCGRT stay-at-home indicator and the Belgian measures).
   - covid_monthly_2017-2024.csv: 4 areas (BE + 3 regions) x 96 months: accidents, severe, Severity Ratio,
     baseline = same calendar month 2017–2019, % change, SR difference (pp), phase, monthly mobility, stringency.
   - covid_processing_log.txt.
   - Belgium per phase (SR %): baseline 10.21 | pre 9.02 | L1 12.33 | summer 9.65->10.60 | L2 9.65 | reopening 9.70 | post 9.35.

3. App (App/app.py, App/data.py)
   - New main tab "🦠 COVID lockdowns": area buttons (Belgium/Flanders/Wallonia/Brussels); per lockdown:
     accidents, severe accidents and SR vs normal + chi-square test; monthly accidents and SR 2017–2024 with
     shaded phases; stringency + Google mobility; scatter region-month mobility vs accident change / SR change;
     "Why": accident mix vs normal, SR within each accident type, decomposition mix effect vs within effect
     (standardised on built-up area x road type x collision type x cyclist); explanation + caveats;
     expander with phases, processed table, raw mobility (with missing %), raw OxCGRT (Belgium).
   - Processed Data Explorer: added covid_monthly and covid_phases to the tables list.
   - Tested with streamlit AppTest (all areas, both lockdowns, both scatter options): no exceptions.
   - Fixed wording: headline is neutral (Brussels SR went DOWN in L1); within-effect sign explained.

4. Result (Belgium)
   - Lockdown 1: 42% fewer injury accidents, SR 12.3% vs 10.2% normal (p = 1.6e-06).
     Mix effect +0.49 pp, within effect +1.68 pp -> mainly "same accident, worse outcome" (fits higher speeds on
     empty roads). Cyclist share 22% -> 32%, single-vehicle 20% -> 24%, motorway 7.8% -> 5.8%.
   - Lockdown 2: 25% fewer accidents, SR 9.6% vs 9.7% (p = 0.85) -> no severity effect.
   - Brussels: fewer accidents in L1 but no SR increase (4.0%).
